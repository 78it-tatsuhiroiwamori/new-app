## Claude Code のセキュリティ設定について

チーム共有の権限ルールは `.claude/settings.json` にあります。Bash と PowerShell のルールはコマンド文字列とのワイルドカード照合なので、次の抜けは設定だけでは防げません。

- 環境変数の値は、`echo $GH_TOKEN`（Bash）や `$env:GH_TOKEN`（PowerShell）のように変数を直接参照すれば表示できます。
- 削除コマンドは、別名・パイプ・スクリプト内での実行など、書き方を変えれば照合をすり抜けられます。
- 新しい書き方が見つかるたびにルールを足す方式なので、網羅はできません。

そのため、次の対策も併用してください。

- 秘密情報は環境変数やリポジトリ内に置かず、必要なときだけ読み込む。
- `main` ブランチにはブランチ保護を設定する（force push と直接 push の禁止）。
- 作業ツリーは小まめにコミットし、削除されても戻せる状態にしておく。
- ask のプロンプトが出たら、実行されるコマンドを読んでから承認する。
